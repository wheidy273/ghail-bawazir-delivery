# غيل باوزير توصيل — مشروع Flutter أولي

هذا مشروع بداية لتطبيق توصيل طلبات لأندرويد، مخصص مبدئيًا لمدينة غيل باوزير في حضرموت.

## الموجود حاليًا
- واجهة عربية باتجاه RTL.
- صفحة رئيسية وأقسام للمطاعم والبقالات والصيدليات وغيرها.
- بحث وتصنيف تجريبي.
- صفحة طلباتي وحسابي.
- توضيح أدوار العميل وصاحب المحل والمندوب والمدير.
- نموذج أولي لسلة الطلبات.
- مخطط SQL مبدئي لقاعدة بيانات Supabase.

## مهم جدًا
هذه **نسخة واجهات تجريبية** وليست بعدُ نظام توصيل حيًا. المحلات والبيانات المعروضة أمثلة، والطلب لا يصل إلى محل حقيقي. لتفعيل التشغيل الحقيقي نحتاج:
1. إنشاء مشروع Supabase أو خدمة خلفية مناسبة.
2. إعداد تسجيل الدخول والتحقق من أرقام الهاتف.
3. تطبيق سياسات RLS واختبارها.
4. ربط المنتجات والطلبات بقاعدة البيانات.
5. إنشاء شاشات عمل فعلية للمحلات والمندوبين والإدارة.
6. تحديد رسوم التوصيل والعمولة، ثم اختبار التطبيق في غيل باوزير.
7. إعداد صور المحلات والمنتجات، وخدمة خرائط/مواقع عند الحاجة.

## طريقة التشغيل على كمبيوتر عليه Flutter SDK
1. فك ضغط المشروع.
2. افتح الطرفية داخل مجلد `ghail_bawazir_delivery`.
3. نفّذ:
   ```bash
   flutter pub get
   flutter run
   ```
4. لبناء APK تجريبي:
   ```bash
   flutter build apk --debug
   ```
   ولنسخة إصدار بعد اكتمال الإعدادات:
   ```bash
   flutter build apk --release
   ```
   سيظهر ملف APK عادةً داخل `build/app/outputs/flutter-apk/`.

## فتحه من الهاتف
يمكنك الاحتفاظ بالمشروع على الهاتف، لكن بناء Flutter APK مباشرة على أندرويد ليس مدعومًا بالطريقة القياسية مثل الكمبيوتر. يمكن استخدام بيئة بناء سحابية أو كمبيوتر عند الوصول إلى مرحلة البناء.

## العمل التجاري
النموذج الذي اخترته:
- تطبيق واحد، تتغير الوظائف حسب نوع الحساب.
- عمولة من المحلات ورسوم توصيل من العملاء.
- نسخة متكاملة مستهدفة، تُبنى على مراحل.

قبل الإطلاق، لا تستخدم بيانات عملاء حقيقية حتى تُستكمل المصادقة والصلاحيات واختبارات الأمان.
